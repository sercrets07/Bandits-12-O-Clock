# Bandits-12-O-Clock
I originally thought of this mod idea back in 2024, and while it has been a slow learning process, I am happy to say the V1.0 Release is here! Introducing Bandits! 12 O'Clock which is a mod that allows triggerable sound lines inside 1946!

It allows mission builders to create contextual voice lines, sound effects, warnings, and other audio events that react to what the player is actually doing in-game. Instead of relying only on IL-2's normal mission triggers, Bandits can react to things such as the player's position, altitude, airspeed, engine RPM, engine temperature, bank angle, and more.


## How it works:
Bandits, Twelve O'Clock! adds mission audio without requiring custom mission objects. The game
sends the player's live coordinates to the companion app. The app reads IL-2's log to identify the
current mission, loads that mission's companion files, and checks the player's position and aircraft
data against configured triggers and rules.

## What can it do? 
Bandits uses a companion application alongside IL-2 1946 to handle trigger calculations and audio playback.
Mission builders can create rules such as:
Play a radio message when the player enters a certain area.
Have an instructor tell the player to reduce speed.
Wait until the player has maintained the correct speed for a set amount of time before continuing.
Play dialogue when an engine starts.
Detect engine RPM on individual engines of multi-engine aircraft.
Trigger warnings based on altitude or aircraft attitude.
React to engine temperature.
Play sounds when the player reaches or leaves designated areas.
Require several conditions to be met before an event occurs.
Create repeatable or one-time events.
Require a condition to remain true for a specified amount of time.
This allows missions to respond to the player rather than simply playing events on a fixed timer.
